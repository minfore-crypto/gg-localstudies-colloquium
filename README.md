이 기록은 **확정본이 아닙니다.** 발표문·토론문과 당일 발언을 바탕으로 경기도문화원연합회가 정리한 것이며, 연합회와 경기학회가 쟁점과 합의를 확정하기 전 단계의 검토본입니다.

사실과 다른 부분을 알려 주시면 그대로 수정합니다. 인용하실 문장은 자료집 원문에서 가져와 주십시오.

검색엔진 색인은 `robots.txt`와 `noindex` 메타 태그로 차단해 두었습니다.
